# 高频风险分类

本分类用于选择探索方向，不是缺陷判定标准。只根据当前页面能力、需求交接和已观察关系选择适用项。

## 交互与跳转

| 风险模式 | 重点观察 |
| --- | --- |
| 入口不可达或目标错误 | 点击前后 URL、标题、面包屑、对象身份和返回位置 |
| 控件状态与动作不一致 | 禁用态、加载态、重复点击、弹窗关闭和取消结果 |
| 上下文丢失 | 筛选、分页、页签、返回后是否保留合理上下文 |
| 操作反馈缺失 | 是否出现明确反馈，反馈是否与实际状态一致 |

## 表单与校验

| 风险模式 | 重点观察 |
| --- | --- |
| 必填或格式校验遗漏 | 空值、空白、非法格式、错误定位和修正后恢复 |
| 长文本处理异常 | 输入、计数、截断、布局、保存、回显和服务端拒绝 |
| 前后端口径不一致 | 客户端允许但保存失败，或错误提示与字段规则冲突 |
| 失败后产生副作用 | 校验失败后是否残留记录、状态、附件或重复数据 |

## 展示结构

| 风险模式 | 重点观察 |
| --- | --- |
| 字段缺失或层级错误 | 列表、详情、弹窗和摘要是否表达同一对象 |
| 文本溢出或遮挡 | 长文本、窄窗口、空值、特殊字符下的可读性 |
| 空态或异常态不可理解 | 无数据、无结果、无权限、加载失败是否可区分 |
| 动作与对象关系不清 | 行级与批量动作是否对应正确对象和选中范围 |

## 流程与状态

| 风险模式 | 重点观察 |
| --- | --- |
| 非法状态仍可操作 | 当前状态下按钮、菜单和接口结果是否自洽 |
| 操作后状态未闭环 | 页面提示、状态、日志、列表和详情是否同步 |
| 重复操作产生重复结果 | 双击、刷新、返回后重试是否重复创建或重复流转 |
| 取消或撤回不完整 | 状态恢复、数据残留、后续动作和关联对象 |

## 数据一致性

| 风险模式 | 重点观察 |
| --- | --- |
| 输入与回显不一致 | 空格、换行、长文本、特殊字符和默认值 |
| 列表与详情不一致 | 名称、状态、数量、时间、归属和更新时间 |
| 明细与汇总不一致 | 计数、统计、分页总数、筛选结果和导出范围 |
| 刷新后持久化异常 | 保存后刷新、重新进入或重新查询的结果 |

## 条件性风险

- 页面存在异步加载、处理中状态或明显网络依赖时，检查等待、刷新和恢复。
- 页面存在文件、二维码、移动端或跨角色能力时，只记录当前执行环境能证明的部分。
- 精确文案是否符合产品规范需要可靠需求来源；没有来源时只检查可理解性、一致性和明显错别字。
